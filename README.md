# The Last Bastion — AI Game Development Package

Полный пакет постановки задачи для AI coding agent на разработку браузерной Tower Defense игры.

## Главный документ

Начинать работу с:

- `MASTER_AI_TASK.md` — основной мастер-промт/ТЗ для AI-агента.

Дополнительные документы:

- `docs/GAME_DESIGN_DOCUMENT.md` — геймдизайн, игровой цикл, карты, башни, враги, боссы, экономика.
- `docs/TECHNICAL_ARCHITECTURE.md` — архитектура браузерной игры и требования к поддерживаемости.
- `docs/ART_DIRECTION.md` — визуальный стиль и правила производства графики.
- `docs/AUDIO_AND_ANIMATION.md` — музыка, SFX, VFX и анимации.
- `docs/STORY_AND_WORLD.md` — мир, сюжет и структура кампании.
- `docs/CONTENT_PIPELINE.md` — как добавлять новые карты, врагов, башни и контент без изменения ядра.
- `docs/QA_AND_RELEASE.md` — тестирование, производительность, сохранения и релиз.
- `specs/ASSET_MANIFEST.md` — список обязательных игровых ассетов.
- `specs/examples/` — примеры конфигураций контента.

## Рабочее название

**The Last Bastion** / **Последний рубеж**.

Название считается временным и должно храниться в одном конфигурационном месте, чтобы его можно было заменить без поиска по исходникам.
